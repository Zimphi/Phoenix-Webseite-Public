# Phoenix-Webseite-Public

Veröffentlichungsrepository für die linkfreie Phoenix-404-Seite unter https://epassport-simulator.de.

## Freigabe und Umfang

Der Eigentümer hat am 1. November 2026 ausdrücklich die öffentliche Sichtbarkeit von `Zimphi/Phoenix-Webseite-Public` und die Bereitstellung über GitHub Pages freigegeben. Geprüft wurden sämtliche Commits und Dateien der frischen Repository-Historie.

Veröffentlicht werden ausschließlich `index.html`, `404.html`, `fdroid.css` und `phoenix.png`. Beide HTML-Dateien zeigen dieselbe 404-Ansicht ohne Links. Die vollständige Projektwebseite, Anwendungen und Downloads sind nicht Bestandteil dieser Freigabe.

Der Pages-Workflow läuft nur manuell auf `main` mit `publish_404: true` und prüft zusätzlich `holdingPublicationApproved`. Es gibt keine automatische Veröffentlichung bei Push. Die eigene Domain wird in den Pages-Einstellungen konfiguriert.
